## Chapter 1: Basics

| Formula | Name |
|:---|:---|
| $\bar{y} = \frac{1}{n}\sum_{i=1}^n y_i$ | Sample mean |
| $s^2 = \frac{1}{n-1}\sum_{i=1}^n (y_i - \bar{y})^2$ | Sample variance (definitional) |
| $s^2 = \frac{\sum y_i^2 - n\bar{y}^2}{n-1}$ | Sample variance (shortcut) |
| $s = \sqrt{s^2}$ | Sample standard deviation |
