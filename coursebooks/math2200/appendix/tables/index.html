Distribution Tables

MATH 2200 — how to read z, t, χ², and F tables

Before software, statisticians read probability tables to turn a distribution into a number (a probability or a critical value). You will mostly use R — pnorm, qt, and friends — but reading a table by hand cements what those functions actually do, and many exams still hand you one. This appendix explains how to read each table and then generates small reference tables with live R code so the values are computed, never transcribed.

The one idea behind every table

A distribution table answers one of two questions:

  • “How much area?” Given a cutoff value, what proportion of the distribution lies beyond it? (This is a probability — R: pnorm, pt, pchisq, pf.)

  • “What cutoff?” Given a tail area you want, what value marks it off? (This is a critical value or quantile — R: qnorm, qt, qchisq, qf.)

Confidence intervals need critical values (the “what cutoff?” direction); p-values need areas (the “how much area?” direction).

# Round helper so every printed table is tidy and reproducible.
fmt <- function(x, d = 4) formatC(x, format = "f", digits = d)

11. The standard Normal (z) table¶

The z-table gives the area to the left of a z-score under the standard Normal curve N(0,1)N(0, 1)N(0,1). To find the area to the right, subtract from 1; the curve’s symmetry means the area below −z-z−z equals the area above +z+z+z.

  • R for an area (left tail): pnorm(z)

  • R for a critical value: qnorm(area_to_left)

A two-sided C%C\%C% confidence interval uses the critical value z⋆z^\starz⋆ that puts (1−C)/2(1-C)/2(1−C)/2 in each tail, i.e. qnorm(1 - (1 - C)/2).

z   <- c(-2, -1.5, -1, -0.5, 0, 0.5, 1, 1.5, 1.96, 2, 2.5)
data.frame(z = z, `area_left_P(Z<z)` = fmt(pnorm(z)), check.names = FALSE)
conf <- c(0.80, 0.90, 0.95, 0.98, 0.99)
data.frame(
  confidence_level = paste0(conf * 100, "%"),
  tail_area_each   = fmt((1 - conf) / 2),
  z_star           = fmt(qnorm(1 - (1 - conf) / 2))
)

The 68–95–99.7 rule is just three z-areas; here are the exact figures:

k <- 1:3
data.frame(
  within_k_SD = k,
  exact_area  = fmt(pnorm(k) - pnorm(-k)),
  rounded     = c("68%", "95%", "99.7%")
)

22. The t table¶

The t-distribution is used for inference about means when σ\sigmaσ is unknown. It is bell-shaped but heavier-tailed than the Normal; its shape depends on the degrees of freedom (dfdfdf). As dfdfdf grows, the t-table converges to the z-table (look at the bottom row below).

  • R for a critical value: qt(1 - tail_area, df)

  • A two-sided C%C\%C% CI for a mean uses qt(1 - (1 - C)/2, df) with df=n−1df = n-1df=n−1.

dfs   <- c(1, 5, 10, 15, 20, 30, 50, 100, Inf)
levels_c <- c(0.90, 0.95, 0.99)
tbl <- sapply(levels_c, function(C) qt(1 - (1 - C) / 2, dfs))
out <- data.frame(df = ifelse(is.finite(dfs), as.character(dfs), "Inf (= z)"),
                  check.names = FALSE)
out[paste0("t*_", levels_c * 100, "%")] <- fmt(tbl)
out
Worked read

For a 95% CI with n=11n = 11n=11 (so df=10df = 10df=10), the table gives t⋆=t^\star =t⋆= Unexecuted inline expression for: fmt(qt(0.975, 10), 3). Compare it to the Normal’s z⋆=z^\star =z⋆= Unexecuted inline expression for: fmt(qnorm(0.975), 3): the t-value is a little larger, widening the interval to pay for not knowing σ\sigmaσ. Both numbers were computed by the R chunk above.

33. The chi-square (χ²) table¶

The chi-square distribution is right-skewed and lives on [0,∞)[0, \infty)[0,∞). We use it for goodness-of-fit and independence tests, which are always one-sided (upper tail): only large χ2\chi^2χ2 values count as evidence against the null.

  • R for an upper-tail critical value: qchisq(1 - alpha, df)

  • R for a p-value from a statistic: pchisq(stat, df, lower.tail = FALSE)

Degrees of freedom: k−1k - 1k−1 for goodness of fit (kkk categories); (r−1)(c−1)(r-1)(c-1)(r−1)(c−1) for an r×cr \times cr×c independence table.

df_chi <- c(1, 2, 3, 4, 5, 6, 8, 10)
alphas <- c(0.10, 0.05, 0.01)
m <- sapply(alphas, function(a) qchisq(1 - a, df_chi))
out <- data.frame(df = df_chi)
out[paste0("alpha=", alphas)] <- fmt(m, 3)
out

44. The F table¶

The F-distribution is used in ANOVA to compare variances. It is right-skewed and indexed by two degrees of freedom: the numerator df1=k−1df_1 = k - 1df1​=k−1 (number of groups minus one) and the denominator df2=N−kdf_2 = N - kdf2​=N−k (total observations minus number of groups). ANOVA tests are upper-tailed: large FFF means the group means differ.

  • R for a critical value: qf(1 - alpha, df1, df2)

  • R for a p-value: pf(F_stat, df1, df2, lower.tail = FALSE)

Because FFF needs two dfdfdf’s, a printed table fixes α\alphaα (here 0.05) and lays df1df_1df1​ across the top, df2df_2df2​ down the side:

df1_vals <- c(1, 2, 3, 4, 5)
df2_vals <- c(5, 10, 15, 20, 30, 60, 120)
fmat <- outer(df2_vals, df1_vals, function(d2, d1) qf(0.95, d1, d2))
out <- data.frame(df2 = df2_vals)
out[paste0("df1=", df1_vals)] <- fmt(fmat, 3)
out
Worked read

A one-way ANOVA with k=3k = 3k=3 groups and N=33N = 33N=33 observations has df1=2df_1 = 2df1​=2 and df2=30df_2 = 30df2​=30. The α=0.05\alpha = 0.05α=0.05 critical value is F⋆=F^\star =F⋆= Unexecuted inline expression for: fmt(qf(0.95, 2, 30), 3) (row df2=30df_2 = 30df2​=30, column df1=2df_1 = 2df1​=2 above). If your computed FFF exceeds this, reject the null that all three means are equal.

Why we still teach the tables

The R functions and the printed tables answer the same two questions (“how much area?” / “what cutoff?”). Reading a table once makes pnorm and qt stop feeling like magic — you can always sanity-check software against the reference tables generated on this page.
