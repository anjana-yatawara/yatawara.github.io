# Which method do I use?

By Week 13 you know two families of inference — one proportion and one mean — and
two things you can do with each — build a confidence interval, or run a hypothesis
test. That is four total procedures. The hard part is rarely the arithmetic; it's
picking the right one of the four from a paragraph of English. This guide walks you
there in a few short questions, and points you to the matching formula, calculator
menu, and R function every time.

:::{tip} Two questions decide almost everything
1. **What kind of variable is being summarized?** A **category/label** (yes/no,
   pass/fail, favors/opposes) → you're working with a **proportion**. A **number**
   you could average (a time, a price, a score, a length) → you're working with a
   **mean**.
2. **What does the problem want from you?** A **range of plausible values** for the
   unknown parameter → build a **confidence interval**. A **decision about a specific
   claimed value** → run a **hypothesis test**.
:::

---

## 1. The decision tree

```
Is the variable categorical (yes/no, success/failure) or numerical (a measured amount)?
│
├── CATEGORICAL → you are estimating or testing a PROPORTION (p)
│     │
│     ├── Does the question ask "what's a plausible range for p?"
│     │     → CONFIDENCE INTERVAL for one proportion
│     │       TI: 1-PropZInt   |   R: prop.test(x, n)$conf.int
│     │
│     └── Does the question give a specific claimed value p0 to check?
│           ("is it 90%?" "test the claim that...")
│           → HYPOTHESIS TEST for one proportion
│             TI: 1-PropZTest   |   R: prop.test(x, n, p = p0, alternative = ...)
│
└── NUMERICAL → you are estimating or testing a MEAN (μ)
      │
      ├── Does the question ask "what's a plausible range for μ?"
      │     → CONFIDENCE INTERVAL for one mean
      │       TI: TInterval   |   R: t.test(~y, data=, mu=) or tsum.test(...)$conf.int
      │
      └── Does the question give a specific claimed value μ0 to check?
            ("is the true mean 25?" "test the claim that...")
            → HYPOTHESIS TEST for one mean
              TI: T-Test   |   R: t.test(~y, data=, mu = μ0) or tsum.test(..., mu = μ0)
```

Reading a problem for its **variable type** (categorical → proportion; numerical →
mean) and its **verb** (estimate/plausible range → interval; test/claim/is it true
that → hypothesis test) is the whole procedure. Everything below fills in the
details of each branch.

## 2. The master decision table

| Response type | Goal | Procedure | TI-83/84 | R (`mosaic`/`BSDA`) | Chapter |
|---|---|---|---|---|---|
| Categorical (one proportion) | Estimate | One-proportion z-interval | `1-PropZInt` | `prop.test(x, n)$conf.int` | Ch 6 |
| Categorical (one proportion) | Test a claim | One-proportion z-test | `1-PropZTest` | `prop.test(x, n, p = p0, alternative =)` | Ch 6 |
| Numerical (one mean, $\sigma$ unknown) | Estimate | One-mean t-interval | `TInterval` | `t.test(~y, data=)` or `tsum.test(...)$conf.int` | Ch 7 |
| Numerical (one mean, $\sigma$ unknown) | Test a claim | One-mean t-test | `T-Test` | `t.test(~y, data=, mu = μ0)` or `tsum.test(..., mu = μ0)` | Ch 7 |
| Numerical (one mean, $\sigma$ **known**, rare) | Estimate / test | One-mean z-interval / z-test | `ZInterval` / `Z-Test` | `zsum.test(...)` | Ch 5 preview |

Data on hand as a full list, or only summary statistics ($\bar{x}$, $s$, $n$)? Either
way the choice of *procedure* above doesn't change — only which R function you call
does. From summary statistics, use the `BSDA` **`sum`** tests (`tsum.test()`,
`zsum.test()`); with raw data loaded in R, use `t.test()`. See the [R Quick
Reference](r-reference.md).

## 3. Confidence interval or hypothesis test — which does the question want?

| Clue words in the problem | You want |
|---|---|
| "estimate," "plausible range," "how big is," "construct a ___% interval for" | **confidence interval** |
| "test the claim," "is it true that," "has changed," "is different from," a stated $\alpha$ or significance level | **hypothesis test** |

Every procedure above reports **both** when you run it in R — `prop.test()`,
`t.test()`, and the `BSDA` `*sum.test()` functions each print a test decision *and*
a confidence interval in the same call, so you don't lose anything by running one
when the question technically asked for the other. On the calculator, though, you
must choose the matching menu item (`Int` vs. `Test`) yourself.

## 4. Before you trust any result — check the conditions

Every procedure in this course assumes something about how the data were collected.
Skipping the check doesn't break the arithmetic, but it does break the guarantee
behind "95% confident" or the p-value.

| Procedure | Conditions to check |
|---|---|
| One-proportion interval / test | **Independence** (random sample, or random assignment; each observation doesn't affect another) **and** **success–failure**: interval needs $n\hat p \ge 10$ and $n(1-\hat p) \ge 10$; test needs $np_0 \ge 10$ and $n(1-p_0) \ge 10$ |
| One-mean interval / test (t) | **Independence** (random sample) **and** the population is **approximately Normal**, *or* the sample size is large enough ($n \ge 30$ is the common rule of thumb) that the Central Limit Theorem covers you regardless of the population's shape |

If a condition fails — say, $n\hat p < 10$, or a small, clearly skewed sample —
the Normal/t-based procedure above may give a misleading interval or p-value. Say
so in your conclusion rather than reporting a number you don't trust; your
instructor would rather see "the success–failure condition fails here, so this
z-interval should be interpreted with caution" than a silently invalid answer.

## 5. Worked routing examples

:::{note} Example A — "Estimate the true proportion of CSUB students who support extending library hours."
**Categorical** (support: yes/no), and the verb is **estimate** →
**one-proportion confidence interval**.
```r
prop.test(x = 208, n = 400)   # TI: 1-PropZInt
```
:::

:::{note} Example B — "A flyer claims 90% of CSUB students commute rather than live on campus. Student government surveys $n=120$ students; $x=100$ say they commute. Test the claim."
**Categorical** (commute: yes/no), and there's a specific claimed value ($p_0 =
0.90$) to check → **one-proportion hypothesis test**. (This is Week 13's Worked
Example 2.)
```r
prop.test(x = 100, n = 120, p = 0.90, alternative = "two.sided")  # TI: 1-PropZTest
```
:::

:::{note} Example C — "Estimate the true mean nap length for CSUB students who nap between classes, from a random sample of 24 students ($\bar x = 25.5$ min, $s = 12.24$ min)."
**Numerical** (nap length, in minutes), and the verb is **estimate** →
**one-mean confidence interval**. (This is Week 14's Worked Example 1.)
```r
tsum.test(mean.x = 25.5, s.x = 12.24, n.x = 24)   # TI: TInterval
```
:::

:::{note} Example D — "CSUB's parking office advertises a 20-minute average commute. A sample of $n=45$ commuter students averages 23.49 minutes with $s = 9.39$ minutes. Many suspect the true average is longer. Test the claim."
**Numerical** (commute time, in minutes), and there's a specific claimed value
($\mu_0 = 20$) with a directional suspicion ("longer than") → **one-mean, one-sided
hypothesis test**. (This is Week 14's Worked Example 2.)
```r
tsum.test(mean.x = 23.49, s.x = 9.39, n.x = 45, mu = 20, alternative = "greater")   # TI: T-Test
```
:::

:::{tip} When in doubt, describe before you decide
`favstats(~ y, data = D)` or a quick `tally(~ y, data = D)` shows you the variable
type and a first look at the shape and spread — often enough, on its own, to tell
you which branch of the tree above you're on before you commit to a procedure. See
the [R Quick Reference](r-reference.md).
:::
